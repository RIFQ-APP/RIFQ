# رِفْق | RIFQ

منصة إسلامية متكاملة — تعلّم برفق، وافهم بعمق، واستمر بخطوات ثابتة.

## التشغيل

```bash
npm install
npx prisma db push
npm run dev
```

## المميزات

### موسوعة التفسير (كاملة عبر API)
- **8 مصادر:** الميسر، الجلالين، السعدي، المختصر، ابن كثير، القرطبي، البغوي، الوسيط
- تفسير لكل آية من 114 سورة
- وضع **مقارنة مصادر** جنباً إلى جنب
- متاح من المصحف (زر تفسير) ومن `/tafsir`

### التجويد (17 درساً كاملاً)
مقدمة، مخارج، صفات، نون، ميم، غنة، مدود، قلقلة، تفخيم، لام شمسية/قمرية، همزة وصل، وقف وابتداء، إدغام عام، سكت، روم وإشمام، بسملة، منهج التمرين

### أخرى
مصحف + 6 قراء | حفظ | أذكار | حديث | سيرة | فقه | اختبارات | خطة تعلم | بحث | وضع داكن | حسابات

## المصادر التقنية للتفسير
- api.alquran.cloud (الميسر، الجلالين، القرطبي، البغوي، الوسيط)
- spa5k/tafsir_api (ابن كثير، السعدي، المختصر)

لا يُنشأ تفسير بالذكاء الاصطناعي — كله منقول من مصادره.
